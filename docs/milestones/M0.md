## How to finish M0

1. **Run it under Godot.** Either push this repo to GitHub, where CI runs everything and uploads the APK, or turn on network access for the workspace and start a new session with this repo attached. That session installs Godot, fixes anything the first run reveals, records the golden hashes and adds the plugin download script.
2. **Phone, part 1 (no accounts needed):** install the CI's APK and open **Sim tests**. Every line should say PASS.
3. **Phone, part 2:** do the one-time console setup in `docs/PLUGINS.md`, then run each Plugin Lab check.

## Try it on a desktop

```sh
python3 tools/sync_sim.py
godot --headless --path worker --script res://cli/run_tests.gd
```

The first run prints `NO GOLDEN` for each scenario. Record them with `-- --record "$PWD/sim/tests/golden/expected.json"`, commit the file, and run again.

## Open issues

- **Sim speed.** The build prompt wants a full 180-second raid replayed in under 100 ms on one core. GDScript is far slower than C++, so this is the biggest technical risk. The golden runner prints microseconds per alien-tick on every platform, so the first CI run gives a real number. If it's too slow, the options are leaner GDScript (packed arrays, fewer allocations) or moving the sim core to a GDExtension that both the client and the worker load. The second would change the build prompt's "pure GDScript" rule, so it's the owner's call.
- **Sign-in plugin API.** The Play Games plugin's GDScript names couldn't be confirmed (its README wasn't reachable). The check reports the real names if they differ.
- **Open questions Q1 to Q6** in `docs/DECISIONS.md`.
